# mostafaosama

Personal site of Mostafa Osama. Next.js 16 and Tailwind v4. Rebuilt from zero; see [CLAUDE.md](./CLAUDE.md)
for what is settled so far.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run lint
npm run format
```

- **Background:** `src/components/CornerGlow.tsx` (React Bits Grainient in the top-right corner). Tune it at
  `http://localhost:<port>/studio` while `npm run dev` runs; **Save to site** writes `src/components/glow.settings.json`.
- **CV:** `public/mostafa-osama-cv.pdf`, generated by `scripts/cv/build.py`.
- **Previous design:** the local git tag `trace-v1`.
